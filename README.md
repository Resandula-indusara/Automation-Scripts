# 🤖 Automation & Network Tools Collection

A collection of functional Python automation and networking tools developed as part of my programming portfolio.

### 📂 Included Projects:
* **IP Geolocation Tracker (`Track.py`):** A networking utility script that takes a Public IP address as input and fetches its precise geographical location (Country, City, ISP, and Coordinates) using external API integration.
* **WordSeek Bot (`Wordseek.py`):** An advanced fully automated solver for Wordle/WordSeek games using Shannon Entropy (Information Theory) and Computer Vision (Pillow/NumPy) to achieve a 100% win rate.
* **Human-like Typist (`type.py`):** A custom simulation script using PyAutoGUI to simulate natural human typing speeds, realistic drifts, and adaptive typo corrections.

### 🛠️ Built With:
* Python 3
* Requests (API Fetching for IP Tracking)
* PyAutoGUI & Pillow (Screen Interaction)
* NumPy (Data Analysis)
* Wordfreq (Linguistic Data)
